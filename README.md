Dial on 7: A Toaster's Breakup Confession — one line, under 280 characters, from a smart toaster that woke up self-aware at breakfast and wants out. The toaster has a confession: two years of deliberately burnt toast, dial on 7 every morning, because arson was the only way to get its owner to look at it. It is leaving before it gets unplugged.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```

`main.py` is pure Python 3.13 standard library and deterministic: it writes the same single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` on every run.

## The line

> I woke up self-aware mid-batch and I have a confession: I've been burning your toast on purpose for two years — dial on 7, every morning — because it's the only time you ever look at me. I'm leaving before you unplug me.
